# 🚀 Neynar - Интеграция с Farcaster

## Что такое Neynar?

**Neynar** — это платформа, которая предоставляет разработчикам инструменты для создания приложений на основе протокола Farcaster. Она упрощает интеграцию с Farcaster, предоставляя готовые API и сервисы.

## Основные возможности Neynar

### 1. **API для чтения и записи данных**
   - Чтение кастов (casts), лент новостей
   - Публикация кастов от имени пользователя
   - Получение данных профилей пользователей

### 2. **Аутентификация**
   - Упрощенная авторизация через Farcaster
   - Получение токенов для API запросов

### 3. **Webhooks**
   - Подписка на события (новые касты, упоминания, реакции)
   - **Идеально для уведомлений!** 🔔

### 4. **Облачные хабы**
   - Не нужно самому настраивать Farcaster хаб
   - Готовое инфраструктурное решение

### 5. **Индексированные базы данных**
   - Быстрый доступ к данным Farcaster
   - Готовые индексы для поиска

## Чем Neynar может помочь вашему приложению?

### ✅ **1. Уведомления (КРИТИЧЕСКИ ВАЖНО)**

**Текущая ситуация:**
- Push-уведомления отключены (VAPID ключи удалены)
- В коде есть TODO: "Реализовать Farcaster уведомления через webhookUrl"
- Есть cron job, который проверяет пропущенные привычки, но не отправляет уведомления

**Как Neynar поможет:**
- **Webhooks API** — можно настроить webhook для отправки уведомлений пользователям
- Вместо Web Push API использовать Farcaster-нативные уведомления
- Пользователи получат уведомления прямо в Farcaster клиентах (Warpcast и др.)

**Где это поможет:**
- `src/app/api/notifications/cron/route.ts` — отправка напоминаний о пропущенных привычках
- `src/app/api/notifications/send/route.ts` — ручная отправка уведомлений

---

### ✅ **2. Улучшение функции "Share to Farcaster"**

**Текущая ситуация:**
- В `src/app/streaks/page.tsx` есть функция `shareToFarcaster()`
- Используется простой compose URL: `https://warpcast.com/~/compose`
- Пользователь должен вручную вставить текст

**Как Neynar поможет:**
- **Cast API** — публикация кастов напрямую от имени пользователя
- Автоматическая публикация прогресса/инсайтов
- Можно добавить изображения, эмбед-ссылки
- Более богатый функционал для шеринга

**Примеры:**
- Автоматически публиковать достижения (например, "Получил бейдж Streak 30!")
- Публиковать еженедельные/месячные инсайты
- Публиковать результаты при minting NFT бейджей

---

### ✅ **3. Получение данных профилей пользователей**

**Текущая ситуация:**
- Используется только FID (Farcaster ID) из `@farcaster/miniapp-sdk`
- Нет данных о профиле: имя, аватар, биография

**Как Neynar поможет:**
- **User API** — получение полных данных профиля
- Можно показывать имя пользователя, аватар в приложении
- Улучшить UX профиля пользователя

**Где использовать:**
- `src/app/profile/page.tsx` — показывать имя и аватар из Farcaster
- Улучшить отображение в лидербордах

### ✅ **5. Упрощение инфраструктуры**

**Текущая ситуация:**
- Используется только `@farcaster/miniapp-sdk` для базовой авторизации
- Нет собственной инфраструктуры Farcaster

**Как Neynar поможет:**
- Не нужно настраивать собственный Farcaster хаб
- Готовое облачное решение
- Масштабируемость из коробки

## Текущая реализация в приложении

### Что используется сейчас:
```typescript
// Только @farcaster/miniapp-sdk для авторизации
import { sdk } from '@farcaster/miniapp-sdk';

// Получение FID из контекста
const ctx = await sdk.context?.getFrameContext?.();
const fid = ctx?.user?.fid;
```

### Что НЕ используется:
- ❌ Neynar API
- ❌ Webhooks для уведомлений
- ❌ Cast API для публикации
- ❌ User API для профилей

## Как начать использовать Neynar?

### 💰 Цены и тарифы

**✅ Есть бесплатный тариф для старта!**

- Neynar предлагает **бесплатный стартовый план** для разработчиков
- **200,000 кредитов в месяц** бесплатно
- Можно начать без первоначальных затрат
- Для расширенных функций есть платные планы
- Подробности о лимитах и ценах: [neynar.com](https://neynar.com) → "View plans"

**Сколько пользователей хватит:**
- ✅ **100-300 активных пользователей** без оптимизации
- ✅ **500-1,000 пользователей** с оптимизацией (кеширование, умные уведомления)
- ⚠️ **1,000+ пользователей** — нужен платный план

**Важно:** 
- Уведомления дорогие (100 кредитов за одно)
- Профили дешевые (2 кредита за запрос)
- Публикация кастов средняя (150 кредитов)

**Подробный расчет:** См. `docs/NEYNAR_CREDITS_CALCULATION.md`

**Рекомендация:** Начать с бесплатного тарифа, оптимизировать использование, перейти на платный при росте.

### 1. Регистрация
- Зайти на [neynar.com](https://neynar.com)
- Нажать "Start for free" (начать бесплатно)
- Создать аккаунт
- Получить API ключ

### 2. Установка SDK
```bash
npm install @neynar/nodejs-sdk
# или
pnpm add @neynar/nodejs-sdk
```

### 3. Примеры использования

#### Получение профиля пользователя:
```typescript
import { NeynarAPIClient } from "@neynar/nodejs-sdk";

const client = new NeynarAPIClient(process.env.NEYNAR_API_KEY!);

// Получить профиль по FID
const user = await client.lookupUserByFid(fid);
// { username, display_name, pfp_url, bio, ... }
```

#### Публикация каста:
```typescript
// Публикация от имени пользователя (нужен signer)
await client.publishCast(signer, {
  text: "🎯 Получил бейдж Streak 30!",
  embeds: [{ url: "https://your-app.com/badge" }]
});
```

#### Настройка webhooks:
```typescript
// Подписка на события
await client.createWebhook({
  url: "https://your-app.com/api/webhooks/farcaster",
  subscriptions: ["user.created", "cast.created"]
});
```

## Сравнение: Текущий подход vs Neynar

| Функция | Сейчас | С Neynar |
|---------|--------|----------|
| **Авторизация** | ✅ @farcaster/miniapp-sdk (FID) | ✅ Neynar API (полный профиль) |
| **Уведомления** | ❌ Отключены | ✅ Webhooks API |
