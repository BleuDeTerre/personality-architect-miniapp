# Улучшения кеширования AI функций

## 📋 Резюме

Добавлено кеширование для всех AI функций, где это имеет смысл. Это значительно снижает количество запросов к AI и улучшает производительность.

---

## ✅ Добавлено кеширование

### 1. **Goal Review** (`/api/ai/goal-review`)
- **Кеш:** 24 часа
- **Ключ:** Хеш всех целей + wellness метрики
- **Экономия:** Если пользователь открывает обзор несколько раз в день, используется кеш

### 2. **Goal Breakdown** (`/api/ai/goal-breakdown`)
- **Кеш:** 7 дней
- **Ключ:** Название цели, описание, дедлайн, важность/срочность
- **Экономия:** Разбивка цели не меняется, если цель не изменилась

### 3. **Wheel Insights** (`/api/ai/wheel-insights`)
- **Кеш:** 24 часа
- **Ключ:** Хеш трендов wheel + привычки + wellness метрики
- **Экономия:** Wheel обновляется раз в неделю, инсайты можно кешировать на день

### 4. **Coach Advice** (`/api/insight/coach`)
- **Кеш:** 6 часов
- **Ключ:** Хеш трендов wheel + цели + weekly summary + wellness метрики
- **Экономия:** Данные могут меняться чаще, поэтому кеш короче (6 часов)

### 5. **Monthly Insight** (`/api/pro/insight/monthly` и `/api/paid/insight/monthly`)
- **Кеш:** 7 дней
- **Ключ:** Месяц + deep флаг
- **Экономия:** Исправлена проблема - теперь проверяется кеш ПЕРЕД генерацией (раньше только возвращался `cachedUntil`, но кеш не проверялся)

## 🔧 Технические детали

### Новая библиотека: `src/lib/aiCacheHelper.ts`

Создан helper для единообразного кеширования AI результатов:

```typescript
// Получить из кеша
const cached = await getAICache<T>(supa, userId, {
    endpoint: 'ai/goal-review',
    input: cacheKey,
    cacheHours: 24,
});

// Сохранить в кеш
await setAICache(supa, userId, {
    endpoint: 'ai/goal-review',
    input: cacheKey,
    cacheHours: 24,
}, response);
```

### Используется таблица `ai_reports`

- `user_id` - ID пользователя
- `endpoint` - название эндпоинта (например, `ai/goal-review`)
- `input_hash` - SHA256 хеш входных данных
- `content` - JSON с результатом
- `cached_until` - срок действия кеша

### До улучшений:
- **Goal Review:** Каждый запрос = 1+ AI запросов (по количеству целей)
- **Goal Breakdown:** Каждый запрос = 1 AI запрос
- **Wheel Insights:** Каждый запрос = 1 AI запрос
- **Coach Advice:** Каждый запрос = 1 AI запрос
- **Monthly Insight:** Каждый запрос = 1 AI запрос (даже если данные не изменились)

### После улучшений:
- **Goal Review:** 1 AI запрос в 24 часа (если цели не изменились)
- **Goal Breakdown:** 1 AI запрос в 7 дней (если цель не изменилась)
- **Wheel Insights:** 1 AI запрос в 24 часа (если wheel не изменился)
- **Coach Advice:** 1 AI запрос в 6 часов (если данные не изменились)

Если пользователь:

**Итого:** ~4 запроса DeepSeek на пользователя в день экономии

При 280 активных пользователях: **~1,120 запросов DeepSeek/день экономии** 🎉

## 🔍 Как проверить кеширование

### В ответе API:
- Если результат из кеша, в ответе будет поле `cached: true`
- Также может быть поле `cachedUntil` с датой истечения кеша

### В базе данных:
```sql
SELECT * FROM ai_reports 
WHERE user_id = '...' 
  AND endpoint = 'ai/goal-review'
  AND cached_until > NOW();
```

## ⚠️ Важные моменты

### Инвалидация кеша
Кеш автоматически инвалидируется по истечении срока (`cached_until`).

### Когда кеш НЕ используется:
1. Данные изменились (новый хеш входных данных)
2. Кеш истек (прошло больше часов, чем `cacheHours`)
3. Пользователь хочет обновить (можно добавить параметр `?force=true` в будущем)

### Производительность
- Кеш хранится в базе данных (`ai_reports`)
- Проверка кеша - быстрая операция (индекс по `user_id`, `endpoint`, `input_hash`)
- Экономия времени: вместо 2-26 секунд на AI запрос - мгновенный ответ из кеша
