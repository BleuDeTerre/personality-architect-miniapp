# Расчет количества пользователей в день

## 📊 Лимиты AI

### Gemma 3
- **RPD:** 15,000 запросов/день (лимит Google AI Studio)
- **TPM:** 15,000 токенов/минуту
- **Используется для:** Daily AI Tip (1 функция)
- **Кеш:** Daily Tip кешируется на 24 часа, поэтому реальное использование намного меньше

### DeepSeek R1T2 Chimera
- **RPD:** 980 запросов/день (глобальный лимит для ВСЕХ пользователей)
- **Используется для:** 9 функций (Chat, Goal Review, Goal Breakdown, Wheel Insights, Coach Advice, Weekly/Monthly/Habit/General Insights)

### Пользовательские лимиты
- **Free:** 5 запросов DeepSeek/день
- **Pro/Premium:** 20 запросов DeepSeek/день

---

## 🎯 Функции с AI и их использование

### Gemma (Daily AI Tip)
- **Автоматически:** При загрузке главной страницы
- **Кеш:** 24 часа (один запрос на пользователя в день)
- **Лимит:** Практически не ограничен (43,200/день, но с кешем реальное использование ~1 запрос/пользователь/день)

### DeepSeek функции (9 функций)
1. **Chat Message** - по запросу пользователя (интерактивный)
2. **Goal Review** - по кнопке
3. **Goal Breakdown** - по кнопке
4. **Wheel Insights** - по кнопке
5. **Coach Advice** - по кнопке
6. **Weekly Insight** - при открытии страницы
7. **Monthly Insight** - при открытии страницы
8. **Habit Review** - при открытии страницы
9. **General Insight** - при открытии страницы

## 📈 Сценарии использования

### Сценарий 1: МАКСИМАЛЬНЫЙ (все используют по максимуму)

**Предположения:**
- Все пользователи используют все доступные функции
- Free пользователи: 5 запросов DeepSeek/день
- Pro/Premium пользователи: 20 запросов DeepSeek/день
- Daily Tip: 1 запрос на пользователя (с кешем)

**Расчет:**

**DeepSeek (ограничивающий фактор):**
- Глобальный лимит: 980 запросов/день
- Если все пользователи используют максимум:
  - Free пользователь: 5 запросов
  - Pro/Premium пользователь: 20 запросов

**Предположим распределение пользователей:**
- 80% Free (5 запросов/день)
- 15% Pro (20 запросов/день)
- 5% Premium (20 запросов/день)

**Формула:**
```
980 = (Free_users × 5) + (Pro_users × 20) + (Premium_users × 20)
980 = (Total_users × 0.8 × 5) + (Total_users × 0.15 × 20) + (Total_users × 0.05 × 20)
980 = Total_users × (0.8 × 5 + 0.15 × 20 + 0.05 × 20)
980 = Total_users × (4 + 3 + 1)
980 = Total_users × 8
Total_users = 122.5 ≈ 122 пользователя
```

**Gemma (Daily Tip):**
- Лимит: 15,000 запросов/день
- С кешем: ~1 запрос/пользователь/день
- Максимум: 15,000 пользователей (не ограничивает в реалистичных сценариях)

**Результат:** ~122 пользователя/день

---

### Сценарий 2: МИНИМАЛЬНЫЙ (пользователи используют минимум)

**Предположения:**
- Пользователи используют только Daily Tip (Gemma)
- DeepSeek функции используются редко:
  - Free: 1-2 запроса/день (в среднем 1.5)
  - Pro/Premium: 3-5 запросов/день (в среднем 4)

**Расчет:**

**DeepSeek:**
```
980 = (Free_users × 1.5) + (Pro_users × 4) + (Premium_users × 4)
980 = Total_users × (0.8 × 1.5 + 0.15 × 4 + 0.05 × 4)
980 = Total_users × (1.2 + 0.6 + 0.2)
980 = Total_users × 2
Total_users = 490 пользователей
```

**Gemma:**
- Не ограничивает (15,000/день, с кешем реальное использование ~1 запрос/пользователь)

**Результат:** ~490 пользователей/день

---

### Сценарий 3: РЕАЛИСТИЧНЫЙ (средний сценарий)

**Предположения:**
- Не все пользователи активны каждый день
- Активные пользователи используют функции умеренно:
  - Free: 2-3 запроса DeepSeek/день (в среднем 2.5)
  - Pro/Premium: 5-10 запросов DeepSeek/день (в среднем 7.5)
- Daily Tip: 1 запрос на активного пользователя (с кешем)
- Активность: ~60% пользователей активны в день

**Расчет:**

**DeepSeek (для активных пользователей):**
```
980 = (Active_Free_users × 2.5) + (Active_Pro_users × 7.5) + (Active_Premium_users × 7.5)
980 = Active_users × (0.8 × 2.5 + 0.15 × 7.5 + 0.05 × 7.5)
980 = Active_users × (2 + 1.125 + 0.375)
980 = Active_users × 3.5
Active_users = 280 активных пользователей/день
```

**Общее количество пользователей:**
```
Total_users = Active_users / 0.6
Total_users = 280 / 0.6
Total_users = 467 пользователей
```

**Gemma:**
- 280 активных пользователей × 1 запрос = 280 запросов/день
- Использование лимита: 280 / 15,000 = 1.87%
- Не ограничивает (15,000/день)

**Результат:** ~467 пользователей (280 активных/день)

## 🎯 Выводы

### Ограничивающий фактор
**DeepSeek (980 RPD)** - это единственное реальное ограничение

### Рекомендации

1. **Для масштабирования:**
   - Увеличить лимит DeepSeek (перейти на платный план OpenRouter)
   - Или оптимизировать использование (больше кеширования, меньше запросов)

2. **Для текущих лимитов:**
   - Реалистично: **~280 активных пользователей/день** (~467 общих)
   - Максимум: **~122 пользователя/день** (если все используют максимум)
   - Минимум: **~490 пользователей/день** (если используют минимум)

3. **Оптимизация:**
   - Кеширование Insights (Weekly/Monthly) на 24 часа
   - Ограничение частоты запросов Chat (rate limiting)
   - Приоритизация Pro/Premium пользователей при достижении лимита

### Если оптимизировать использование (кеширование, rate limiting):
- **Кеширование Weekly/Monthly Insights на 24 часа:**
  - Сейчас: Weekly Insight кешируется на 7 дней (уже реализовано)
  - Можно добавить: Monthly Insight кеширование на 24 часа (сейчас только 7 дней в ответе, но не проверяется)
  - Экономия: ~560 запросов DeepSeek/день (если пользователи открывают Insights несколько раз в день)
  - Результат: можно увеличить количество пользователей на 30-50% без увеличения лимита

**Примечание:** Weekly Insight уже кешируется на 7 дней в таблице `ai_reports`. Monthly Insight возвращает `cachedUntil`, но не проверяет кеш перед генерацией - можно добавить проверку.
