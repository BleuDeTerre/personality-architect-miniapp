# Настройка Neynar MCP Server для Cursor

## 📋 Что это такое?

**MCP (Model Context Protocol)** - это протокол, который позволяет AI ассистентам в Cursor иметь прямой доступ к документации и API спецификациям Neynar. Это значительно улучшает работу с AI, так как он получает полный контекст документации Neynar.

- ✅ `@neynar/nodejs-sdk` установлен и настроен
- ✅ Neynar клиент создан в `src/lib/neynar.ts`
- ✅ API ключ настроен
- ✅ Базовая интеграция работает

## ❌ Чего нет (НО МОЖЕТ БЫТЬ ПОЛЕЗНО)

- ❌ **MCP Server** - не установлен
- ❌ **Конфигурация Cursor** для MCP
- ❌ **Доступ к llms.txt документации** Neynar

## 🎯 Зачем это нужно?

### Преимущества MCP Server:

1. **Улучшенная помощь AI в Cursor:**
   - AI будет знать все методы Neynar API
   - AI сможет предлагать правильные решения на основе документации
   - Меньше ошибок и неточностей в коде

2. **Автоматический доступ к документации:**
   - Не нужно искать документацию вручную
   - AI всегда имеет актуальную информацию
   - Поддержка OpenAPI спецификаций

3. **Улучшенная разработка:**
   - AI лучше понимает структуру вашего проекта
   - Может предлагать правильные паттерны использования Neynar
   - Помогает с отладкой

## 📦 Установка MCP Server

### Шаг 1: Установить MCP Server

```bash
npx @mintlify/mcp@latest add neynar
```

Эта команда:
- Установит MCP server для Neynar
- Настроит его для работы с Cursor
- Добавит необходимые конфигурации

### Шаг 2: Настроить Cursor

После установки MCP server нужно добавить его в настройки Cursor:

1. Открыть настройки Cursor (Settings)
2. Найти раздел "MCP Servers" или "AI Features"
3. Добавить Neynar MCP server
4. Перезапустить Cursor

### Шаг 3: Проверить работу

После настройки можно проверить работу, задав AI в Cursor вопрос о Neynar API. Он должен иметь доступ к документации.

## 🔍 llms.txt документация

Neynar предоставляет два варианта документации для LLM:

1. **Full file LLM Documentation** - полная версия (может быть слишком большой для бесплатных планов)
2. **Abridged version** - компактная версия

**Ссылки:**
- [llms.txt на docs.neynar.com](https://docs.neynar.com/docs/neynar-farcaster-with-cursor#llms.txt)

Эти файлы можно использовать для:
- Добавления в контекст при работе с AI
- Улучшения понимания AI структуры Neynar API
- Справочной документации


**Примечание:** Команда может не работать из-за ошибок в инструменте. В этом случае используйте вариант 2.

### Вариант 2: Ручная настройка через .cursorrules (УЖЕ СДЕЛАНО ✅)

Я уже создал файл `.cursorrules` в корне проекта с:
- Информацией о Neynar интеграции
- Ссылками на документацию
- Примерами использования API
- Структурой проекта

Этот файл автоматически используется Cursor для улучшения контекста AI.

### Вариант 3: Ручная настройка MCP в Cursor (если поддерживается)

1. Открыть Cursor Settings (⌘,)
2. Найти раздел "MCP" или "AI Features"
3. Добавить MCP server вручную:
   ```json
   {
     "mcpServers": {
       "neynar": {
         "command": "npx",
         "args": ["@mintlify/mcp", "neynar"]
       }
     }
   }
   ```
4. Перезапустить Cursor
