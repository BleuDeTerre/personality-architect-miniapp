### ✅ 4. Обновлены API endpoints

#### Возвращают информацию о лимите:
- `/api/chat/message` - возвращает `aiLimit` объект
- `/api/ai/wheel-insights` - возвращает `aiLimit` объект
- `/api/insight/coach` - возвращает `aiLimit` объект

#### Формат ответа:
```typescript
{
  // ... другие данные
  aiLimit: {
    used: number;      // Использовано запросов
    limit: number;     // Лимит (5 для free, 20 для pro)
    remaining: number; // Осталось запросов
  },
  plan: 'free' | 'pro' | 'premium'
}
```

## 🔧 Технические детали

### Предупреждения показываются:
1. **При отправке сообщения в Chat** - проверяется лимит перед запросом
2. **После получения ответа** - показывается предупреждение, если осталось 1-2 запроса
3. **При загрузке Wheel Insights** - предупреждение после загрузки данных

### Логика предупреждений:
- Осталось 2 запроса → `toast.info()`
- Осталось 1 запрос → `toast.warning()` с кнопкой апгрейда (для free)
- Лимит достигнут → `AILimitReachedModal` + toast.error()

### Лимиты:
- **Free:** 5 AI запросов/день
- **Pro:** 20 AI запросов/день
