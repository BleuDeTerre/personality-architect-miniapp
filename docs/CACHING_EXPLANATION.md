# Что такое кеширование Insights? Простое объяснение

## 🎯 Что такое кеширование простыми словами?

**Кеширование** - это сохранение результата, чтобы не вычислять его заново каждый раз.

### Пример из жизни:
Представь, что ты спрашиваешь у друга: "Какая погода сегодня?"
- **Без кеша:** Друг каждый раз идет на улицу, смотрит на небо, проверяет температуру и отвечает
- **С кешем:** Друг один раз проверил утром, записал ответ на бумажке, и весь день просто читает с бумажки

---

## 💡 Как это работает для Weekly/Monthly Insights?

### Сейчас (без кеширования на 24 часа):
1. Пользователь открывает страницу Weekly Insight
2. Система делает запрос к AI (DeepSeek)
3. AI анализирует все данные за неделю
4. AI генерирует отчет
5. Пользователь видит результат

**Проблема:** Если пользователь открывает страницу 5 раз в день, AI делает 5 запросов! 😱

### С кешированием на 24 часа:
1. Пользователь открывает страницу Weekly Insight **в первый раз**
2. Система делает запрос к AI (DeepSeek)
3. AI анализирует все данные за неделю
4. AI генерирует отчет
5. **Система сохраняет результат в базу данных** (кеш)
6. Пользователь видит результат

**Второй раз (в тот же день):**
1. Пользователь открывает страницу Weekly Insight **снова**
2. Система проверяет: "Есть ли сохраненный результат для этой недели?"
3. **Находит сохраненный результат** ✅
4. **Сразу показывает его** - БЕЗ запроса к AI! 🎉
5. Пользователь видит результат (тот же самый)

**На следующий день:**
1. Кеш истекает (прошло 24 часа)
2. Система снова делает запрос к AI
3. Генерирует новый отчет (данные могли измениться)
4. Сохраняет новый результат

---

## 📊 Что это дает?

### Экономия запросов DeepSeek:

**Без кеширования:**
- Пользователь открывает Weekly Insight 3 раза в день
- = 3 запроса DeepSeek на пользователя в день
- 280 активных пользователей × 3 = **840 запросов/день** 😱

**С кешированием на 24 часа:**
- Пользователь открывает Weekly Insight 3 раза в день
- Первый раз: 1 запрос DeepSeek (генерирует отчет)
- Второй и третий раз: 0 запросов (берет из кеша)
- = 1 запрос DeepSeek на пользователя в день
- 280 активных пользователей × 1 = **280 запросов/день** ✅

**Экономия: 840 - 280 = 560 запросов/день!** 🎉

## 🔍 Технические детали

### Как это работает в коде:

1. **Проверка кеша:**
```typescript
// Проверяем, есть ли сохраненный результат
const cached = await checkCache(userId, 'weekly-insight', weekStart);
if (cached && cached.isValid) {
    return cached.result; // Возвращаем из кеша, БЕЗ запроса к AI
}
```

2. **Генерация нового результата:**
```typescript
// Если кеша нет - генерируем через AI
const result = await generateWithAI(data);
```

3. **Сохранение в кеш:**
```typescript
// Сохраняем результат на 24 часа
await saveCache(userId, 'weekly-insight', weekStart, result, 24hours);
```

### Где хранится кеш?
- В базе данных (таблица `ai_reports`)
- Ключ: `user_id + endpoint + week_start`
- Срок действия: 24 часа (или 7 дней для Weekly)

---

## ⚠️ Важные моменты

### Когда кеш НЕ используется:
1. **Новая неделя/месяц** - данные изменились, нужен новый отчет
2. **Кеш истек** - прошло 24 часа (или 7 дней)
3. **Пользователь хочет обновить** - нажал кнопку "Обновить отчет"

### Когда кеш используется:
1. **Та же неделя/месяц** - данные не изменились
2. **Кеш еще действителен** - не прошло 24 часа
3. **Пользователь просто открыл страницу** - не нужно генерировать заново

---

## 🎯 Итог

**Кеширование = экономия запросов к AI**

- Без кеша: каждый раз запрос к AI (дорого, медленно)
- С кешем: один раз запрос, остальные разы - из сохраненного (дешево, быстро)

**Результат:** Больше пользователей могут использовать приложение, потому что меньше запросов к AI! 🚀
