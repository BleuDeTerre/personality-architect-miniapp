# Варианты текстов для кастов
Каждый каст имеет 4 варианта текста для большей живости и естественности. Все тексты написаны от первого лица, живым языком на английском.
---

## 📊 Analytics (Аналитика)
### 1. Weekly Summary (Еженедельная сводка)

**Вариант 1:**
```
📈 I did [X] habits this week. [message].
```
**Вариант 2:**
```
📈 Got [X] habits done this week! [message].
```
**Вариант 3:**
```
📈 Week wrapped up: [X] habits completed. [message].
```
**Вариант 4:**
```
📈 Logged [X] habits this week. [message].
```
*Примечание: emoji меняется в зависимости от тренда (📈 up, 📉 down, 📊 neutral)*

## 💡 Реализация

Все варианты текстов реализованы в `src/lib/castTextVariants.ts` с использованием функции `getRandomVariant()` для случайного выбора варианта при каждом создании каста.

### Использование:

```typescript
import { getRandomVariant, weeklySummaryTexts } from '@/lib/castTextVariants';

const text = getRandomVariant(weeklySummaryTexts(trend, thisWeek, message));
```

## 📸 Детальное описание визуализаций кастов

### Всего кастов: 15

- **Analytics**: 7 кастов (Weekly Summary, Top Habit, Weekly Capsule, Streak Signal, Badge Progress, Goal Pulse, Wheel Shift, Wheel Spotlight)
- **Streaks**: 2 каста (Habit Streak, Next Badge)
- **Wheel**: 4 каста (Snapshot, Focus Area, Shift, Spotlight)
- **Habits**: 2 каста (Top Streak, Summary)
- **Goals**: 3 каста (Progress, Completed, Upcoming)
- **Quests**: 1 каст (Quest Progress)
- **Profile**: 1 каст (Level Up)

## 📊 Analytics (Аналитика)

### 1. Weekly Summary (Еженедельная сводка)
**Variant:** `analytics:weekly` или `analytics:weekly-summary`  
**Kind:** `analytics`

**Изображение показывает:**
- **Заголовок:** "Weekly Habit Summary" с иконкой 📈/📉/📊 (зависит от тренда)
- **Подзаголовок:** Сообщение о неделе
- **Основное значение:** "X vs Y habits" (эта неделя vs прошлая неделя)
- **Визуализация:** Две колонки с прогресс-барами:
  - **This week** (белый текст, жирный) - прогресс-бар с PRIMARY_COLOR (синий), показывает количество привычек
  - **Last week** (серый текст) - прогресс-бар с rgba(248,250,252,0.75) (светло-серый)
  - **Trend indicator** (если есть) - стрелка и текст "Up/Down/Flat vs last week" в соответствующем цвете

**Параметры:** `tw` (this week), `lw` (last week), `trend` (up/down), `msg` или `summary`

**Kind:** `quests`

**Изображение показывает:**
- **Заголовок:** "Quest Progress" с иконкой ⚡
- **Основное значение:** "X completed"
- **Label:** "COMPLETED QUESTS"
- **Чип:** "Daily • Weekly • Monthly" (желтый текст)

**Параметры:** `completed`

## ⭐ Profile (Профиль)

### 1. Level Up (Повышение уровня)
**Variant:** `level:up` или `level`  
**Kind:** `level`

**Изображение показывает:**
- **Заголовок:** "Level Up" с иконкой ⭐
- **Основное значение:** "Level X"
- **Label:** "NEW LEVEL"
- **Чип:** "XP to next: X" или "Total XP: X" или "Level unlocked"
- **Визуализация:** Прогресс-бар до следующего уровня:
  - **XP progress** (белый текст, жирный) - прогресс-бар с градиентом (от #facc15 до #fbbf24, желтый), показывает прогресс до следующего уровня

**Параметры:** `level`, `xp`, `nextXp`, `levelXp`, `levelXpMax`

---

## 🎨 Общие элементы визуализации

Все касты имеют:
- **Центральное окошко** с полупрозрачным фоном (rgba(15,23,42,0.3)) и рамкой, скругление 36px
- **Цветовая схема** зависит от `kind`:
  - `goals` - бирюзовый/зеленый (#10b981)
  - `streaks` - красный/розово-красный (#f87171)
  - `habits` - розовый/коралловый (#f472b6)
  - `wheel` - фиолетовый (#8b5cf6)
  - `analytics` - синий (#3b82f6)
  - `level` - желтый (#facc15)
  - `quests` - оранжевый (#f97316)
- **Прогресс-бары** имеют разные цвета в зависимости от типа данных:
  - Основные метрики - PRIMARY_COLOR (цвет категории)
  - Вторичные метрики - rgba(248,250,252,0.75) (светло-серый)
  - Специальные (бейджи, уровень) - градиенты (желтый, зеленый, фиолетовый)
