---

## ⚠️ Важно понимать

### Запрос СЧИТАЕТСЯ сразу:

1. Когда вы нажимаете "Get Coach Advice" на Wheel → запрос логируется в БД
2. Когда вы задаете вопрос в AI Chat → запрос логируется в БД
3. Когда загружается Daily Motivation → запрос логируется в БД (если не из кэша)

**Все запросы логируются через общее событие `ai_request`** в таблице `events_log`.

## 📊 Проблема с обновлением счетчика

**Счетчик на странице `/chat` обновляется:**
- ✅ При загрузке страницы
- ✅ После отправки сообщения в Chat

**Счетчик НЕ обновляется:**
- ❌ После запросов на других страницах (Wheel, Analytics, etc.)
- ❌ В реальном времени

---

## 💡 Решение

### Вариант 1: Перезагрузить страницу
Если вы сделали AI запрос на другой странице, просто перезагрузите страницу `/chat` - счетчик обновится и покажет правильное значение.

### Вариант 2: Проверить через DevTools
Откройте DevTools → Console и выполните:
```javascript
// Это покажет реальное количество запросов
const today = new Date().toISOString().slice(0, 10);
// Запрос к БД покажет актуальное значение
```

## 🔍 Проверка: считается ли запрос?

### Проверка 1: Перезагрузите страницу `/chat`
После запроса "Get Coach Advice" на Wheel, перезагрузите страницу `/chat` - счетчик должен увеличиться.

### Проверка 2: Проверьте в БД
В Supabase SQL Editor:
```sql
SELECT COUNT(*) 
FROM events_log 
WHERE name = 'ai_request' 
  AND user_id = 'ВАШ_USER_ID'
  AND created_at >= CURRENT_DATE;
```
