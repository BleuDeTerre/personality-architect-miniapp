# 🎨 Дизайн-концепт для NFT бейджей Personality Architect

## Общая концепция

### Стиль
- **Минималистичный flat design** с легким 3D эффектом
- **Градиенты** для глубины (фиолетовый → синий → зеленый)
- **Геометрические формы**: круги, звезды, ромбы, щиты
- **Иконки**: простые символы, понятные на первый взгляд

### Цветовая палитра
- **Фон**: Темный градиент (#0A0B1E → #1A1B2E) или прозрачный
- **Основной цвет**: Фиолетовый градиент (#8B5CF6 → #7C3AED)
- **Акцентные цвета**:
  - Золото (#FFD700) для редких достижений
  - Серебро (#C0C0C0) для средних
  - Бронза (#CD7F32) для базовых
  - Зеленый (#10B981) для успеха
  - Синий (#3B82F6) для прогресса

### Размеры и форматы

#### Для Zora NFT (метаданные):
- **Рекомендуемый размер**: 1024x1024 px или 2048x2048 px
- **Формат**: PNG (лучше всего) или JPEG
- **Особенности**:
  - Квадратное изображение (1:1)
  - Максимальный размер файла: обычно до 10-20 MB (зависит от платформы)
  - PNG с прозрачностью поддерживается
  - SVG обычно не поддерживается для NFT метаданных

#### Для UI приложения (превью):
- **Размер**: 512x512 px или 1024x1024 px (можно меньше, но не больше)
- **Формат**: PNG (лучше всего) или WebP (современный формат)
- **Особенности**:
  - Можно оптимизировать для веба (меньший размер файла)
  - PNG с прозрачностью отлично работает
  - SVG тоже можно, но PNG надежнее

**Рекомендация по форматам**:
1. **Создавайте в высоком разрешении** (1024x1024 или 2048x2048) PNG
2. **Для Zora**: Используйте оригинал (1024x1024+)
3. **Для UI**: Можете использовать тот же файл или оптимизированную версию (512x512)

## Где разместить изображения

### ⚠️ ВАЖНО: Два разных места для изображений!

#### 1. Изображения для Zora NFT (метаданные коллекции)
**Где**: В интерфейсе Zora Creator при создании токенов  
**Обязательно IPFS?**: НЕТ, но рекомендуется

**Варианты**:
- ✅ **Zora сам загружает на IPFS** — когда вы загружаете изображение через их интерфейс, они автоматически размещают на IPFS
- ✅ **Ваш сервер** — можно указать HTTP URL, но это не рекомендуется для NFT (может стать недоступным)
- ✅ **IPFS вручную** — Pinata/NFT.Storage, затем указать IPFS URL в Zora

**Рекомендация**: Используйте интерфейс Zora — они сами загрузят на IPFS бесплатно!

#### 2. Изображения для UI приложения (превью в вашем приложении)
**Где**: `/public/badges/` папка на вашем сервере  
**Обязательно IPFS?**: НЕТ

**Варианты**:
- ✅ **Ваш сервер** (`/public/badges/badge-1.png`) — самый простой способ
- ✅ **CDN** (Vercel, Cloudflare) — быстрая загрузка
- ✅ **IPFS gateway** — можно, но не обязательно (медленнее для UI)

**Рекомендация**: Просто положите в `/public/badges/` — это достаточно!
