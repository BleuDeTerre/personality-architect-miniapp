**Но Gemma 3 27B:**

## 📈 Стратегия масштабирования

### Текущая ёмкость

### ⚠️ КРИТИЧЕСКИ ВАЖНО: Общий лимит OpenRouter

**OpenRouter Free Tier: 1,000 запросов/день ОБЩИЙ для всех моделей!**

Это означает:
- Если DeepSeek использует 980/день → для Llama остаётся **только 20/день**
- Если Llama использует 500/день → для DeepSeek остаётся **только 500/день**
- **НЕ 1,000 для каждой модели, а 1,000 ВСЕГО!**

### Рекомендуемая стратегия

**ВАРИАНТ 1: Оставить Gemma (рекомендуется)**
- Daily Motivation и Habit Difficulty остаются на Gemma (15,000/день отдельно)
- DeepSeek использует 980/день для сложных задач
- **Не конфликтуют!** Gemma и DeepSeek на разных провайдерах

**ВАРИАНТ 2: Перенести Daily Motivation на Llama (рискованно)**
- Daily Motivation (~500 запросов/день) → Llama
- DeepSeek (~500 запросов/день) → сложные задачи
- **Проблема:** При росте пользователей лимит быстро исчерпается

**ВАРИАНТ 3: Перенести простые функции на Llama (если есть запас)**
- Wheel Insights, Coach Advice, Correlation Insights → Llama
- Экономия: ~200-300 DeepSeek запросов/день
- **Но:** Нужно следить за общим лимитом 1,000/день

**ВАРИАНТ 4: При росте → Платный план OpenRouter**
- DeepSeek Chat: $0.14/M input, $0.28/M output
- Llama 3.3: $0.12/M input, $0.30/M output
- Лимиты увеличиваются значительно

## 💡 Финальная рекомендация

### ✅ ОСТАВИТЬ ВСЁ КАК ЕСТЬ (Gemma + DeepSeek)

**Почему:**
1. **Gemma имеет отдельный лимит 15,000/день** (Google AI Studio)
2. **DeepSeek использует OpenRouter 980/день** (почти весь лимит)
3. **Streak Recovery и Predictive Alerts уже не используют AI** (шаблоны)
4. **Перенос Daily Motivation на Llama даст только проблемы:**
   - Daily Motivation (~500 запросов/день) займёт половину лимита OpenRouter
   - Для DeepSeek останется только ~500 запросов/день
   - При росте пользователей лимит быстро исчерпается

### ⚠️ Если всё же переносить на Llama:

**Можно попробовать (с тестированием):**
- Wheel Insights (JSON проще)
- Coach Advice (3-5 пунктов)
- Correlation Insights (анализ связей)

**НО:** Нужно следить за общим лимитом 1,000/день OpenRouter!

### 🚀 При росте до 1000+ пользователей:

1. **Перейти на платный план OpenRouter** ($5-10/месяц)
2. **Или использовать собственный сервер** с моделями
3. **Или оптимизировать кеширование** (увеличить срок кеша)
