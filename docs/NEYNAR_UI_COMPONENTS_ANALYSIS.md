# Анализ Neynar React UI Компонентов

## 📦 О пакете

**Пакет:** `@neynar/react`  
**Версия:** 1.2.20 (последняя, обновлена 2 дня назад)  
**Лицензия:** MIT (бесплатно)  
**Storybook:** https://neynar-react.vercel.app  
**Размер:** ~2.3 MB (unpacked)

## 🎯 Доступные компоненты

### 1. **NeynarAuthButton** ⭐⭐⭐⭐⭐ (ОЧЕНЬ ПОЛЕЗНО)
**Назначение:** Кнопка авторизации "Sign In with Neynar"

**Преимущества:**
- ✅ Готовая кнопка авторизации через Farcaster
- ✅ Поддержка read-only и read+write режимов
- ✅ Настраиваемый дизайн (variant, стили)
- ✅ Встроенная обработка ошибок и состояний

**Когда использовать:**
- Если нужна быстрая интеграция авторизации
- Когда хотите стандартизировать UX авторизации
- Для замены текущего кастомного решения

**Текущая ситуация в проекте:**
- Сейчас используется `@farcaster/miniapp-sdk` + Supabase
- Авторизация через `/api/auth/farcaster-login`
- Можно заменить на NeynarAuthButton для упрощения

**Рекомендация:** ✅ **СТОИТ ВНЕДРЯТЬ** - упростит авторизацию и улучшит UX

---

### 2. **NeynarCastCard** ⭐⭐⭐⭐ (ОЧЕНЬ ПОЛЕЗНО)
**Назначение:** Карточка каста с поддержкой рекастов, лайков, комментариев

**Возможности:**
- Отображение кастов с медиа (изображения, видео)
- Рекасты (recasts)
- Лайки и реакции
- Цитаты (quote casts)
- Фреймы (frames)
- Кастомные стили

**Когда использовать:**
- Для отображения кастов в профиле
- Для создания ленты активности
- Для показа достижений пользователей как касты

**Текущая ситуация в проекте:**
- Нет отображения кастов/рекастов
- Можно использовать для показа активности пользователей
- Можно использовать для "Share to Farcaster" функции

**Рекомендация:** ✅ **СТОИТ ВНЕДРЯТЬ** - добавит функциональность социальной сети

## 📦 Быстрая установка

### Шаг 1: Установить пакет и зависимости

```bash
pnpm add @neynar/react
pnpm add @pigment-css/react hls.js swr
```

### Шаг 2: Добавить CSS в layout.tsx

```tsx
// src/app/layout.tsx
import "@neynar/react/dist/style.css";
// ... остальные импорты
```

### Шаг 3: Настроить NeynarProvider (если нужен)

Для некоторых компонентов может понадобиться провайдер:

```tsx
import { NeynarProvider } from "@neynar/react";

// В layout или нужном компоненте
<NeynarProvider>
  {children}
</NeynarProvider>
```

### Шаг 4: Настроить авторизованный origin (для NeynarAuthButton)

1. Зайти на https://dev.neynar.com
2. Добавить ваш домен (localhost для разработки, production для продакшена)
3. Это нужно для работы кнопки авторизации

## 🚀 Примеры использования

### Пример 1: NeynarProfileCard в профиле

```tsx
// src/app/profile/page.tsx
import { NeynarProfileCard } from "@neynar/react";

// В компоненте, где есть fid:
<NeynarProfileCard 
  fid={fid} 
  viewerFid={fid}
  containerStyles={{ marginBottom: '1rem' }}
/>
```

### Пример 2: NeynarCastCard для отображения каста

```tsx
import { NeynarCastCard } from "@neynar/react";

<NeynarCastCard
  castHash="0x123..."
  allowReactions={true}
  onLike={() => console.log('liked')}
  onRecast={() => console.log('recasted')}
/>
```

### Пример 3: NeynarAuthButton

```tsx
import { NeynarAuthButton } from "@neynar/react";

<NeynarAuthButton 
  label="Sign In with Neynar"
  variant="primary"
  onSuccess={(user) => {
    console.log('User signed in:', user);
    // Сохранить user.fid в Supabase
  }}
/>
```
