# Data Export System (Система экспорта данных)

## 📋 Обзор

Система экспорта данных позволяет пользователям скачать все свои данные в трех форматах: JSON, CSV и Markdown. Все данные экспортируются без технических идентификаторов (ID, FID), содержат только понятную пользовательскую информацию: названия, цифры, даты.

---

## 📦 Что экспортируется

Все три формата (JSON, CSV, Markdown) содержат одинаковый набор данных, представленный в удобном для чтения виде.

### 1. 👤 Профиль пользователя (Profile)

**Поля:**
- `username` - имя пользователя из Farcaster
- `display_name` - отображаемое имя
- `main_focus` - главная цель жизни (North Star / Ikigai)
- `plan` - текущий план подписки (free, pro, premium)
- `plan_until` - дата окончания плана (если применимо)
- `registration_date` - дата регистрации

**Источники данных:**
- Таблица `users` (username, display_name, created_at)
- Таблица `user_profile_settings` (main_focus)
- Таблица `user_plans` (plan, plan_until)

---

### 2. ✅ Привычки (Habits)

**Поля:**
- `title` - название привычки (может содержать emoji)
- `category` - категория привычки (Wellness, Fitness, Mindset, и т.д.)
- `target_days_per_week` - цель выполнения (1-7 дней в неделю)
- `is_active` - активна ли привычка (true/false)
- `created_date` - дата создания привычки

**Источники данных:**
- Таблица `habits` (все привычки пользователя)

---

### 3. 📝 Логи выполнения привычек (Habit Logs)

**Поля:**
- `habit_title` - название привычки (для связи)
- `date` - дата выполнения
- `completed` - выполнено ли (true/false, Да/Нет)

**Источники данных:**
- Таблица `habit_logs` (все логи выполнения привычек)

**Примечание:** В JSON и Markdown логи сгруппированы внутри каждой привычки. В CSV логи представлены отдельной таблицей с указанием названия привычки.

---

### 4. 🎯 Цели (Goals)

**Поля:**
- `title` - название цели
- `metric` - метрика для измерения прогресса
- `target` - целевое значение
- `unit` - единица измерения
- `progress` - текущий прогресс (%)
- `status` - статус цели (active, completed, cancelled)
- `important` - важная ли цель (true/false)
- `urgent` - срочная ли цель (true/false)
- `due_date` - дедлайн цели
- `created_date` - дата создания цели

**Источники данных:**
- Таблица `goals` (все цели пользователя)

---

### 5. 📋 Подзадачи целей (Goal Subtasks)

**Поля:**
- `goal_title` - название родительской цели (для связи)
- `subtask_title` - название подзадачи
- `completed` - выполнена ли подзадача (true/false, Да/Нет)
- `due_date` - дедлайн подзадачи

**Источники данных:**
- Таблица `subtasks` (все подзадачи пользователя)

**Примечание:** В JSON и Markdown подзадачи сгруппированы внутри каждой цели. В CSV подзадачи представлены отдельной таблицей с указанием названия цели.

---

### 6. 🎡 Колесо жизни (Wheel of Life)

**Поля:**
- `week` - неделя оценки (формат: YYYY-WW)
- `area` - область жизни (Health, Career, Relationships, Finance, Personal Growth, Recreation, Family, Friends)
- `score` - оценка от 1 до 10
- `date` - дата оценки

**Источники данных:**
- Таблица `wheel_scores` (все оценки колеса жизни)

**Примечание:** Данные группируются по неделям для удобного просмотра прогресса.

---

### 7. 📊 Метрики благополучия (Wellness Metrics)

**Поля:**
- `date` - дата записи
- `stress_level` - уровень стресса (1-10)
- `productivity_level` - уровень продуктивности (1-10)
- `sleep_hours` - количество часов сна
- `work_hours` - количество рабочих часов

**Источники данных:**
- Таблица `daily_wellness_metrics` (все записи метрик)

---

### 8. 💬 История чата с AI коучем (Chat History)

**Поля:**
- `role` - роль участника (user - пользователь, assistant - AI коуч)
- `content` - текст сообщения
- `date` - дата и время сообщения

**Источники данных:**
- Таблица `chat_messages` (вся история переписки)

---

## 📄 Форматы экспорта

### JSON (.json)

**Структура:**
```json
{
  "profile": { ... },
  "habits": [
    {
      "title": "...",
      "category": "...",
      "logs": [ ... ]
    }
  ],
  "goals": [
    {
      "title": "...",
      "subtasks": [ ... ]
    }
  ],
  "wheel_of_life": [ ... ],
  "wellness_metrics": [ ... ],
  "chat_history": [ ... ],
  "exported_at": "дата экспорта"
}
```

**Особенности:**
- Полная структурированная информация
- Логи привычек и подзадачи целей вложены в родительские объекты
- Удобно для программной обработки
- Легко импортировать в другие приложения

---

### CSV (.csv)

**Структура:**
Файл разделен на секции с заголовками `=== SECTION NAME ===`:

1. `=== PROFILE ===` - профиль пользователя
2. `=== HABITS ===` - список всех привычек
3. `=== HABIT LOGS ===` - все логи выполнения (отдельная таблица)
4. `=== GOALS ===` - список всех целей
5. `=== GOAL SUBTASKS ===` - все подзадачи (отдельная таблица)
6. `=== WHEEL OF LIFE ===` - все оценки колеса жизни
7. `=== WELLNESS METRICS ===` - все метрики благополучия
8. `=== CHAT HISTORY ===` - вся история чата

**Особенности:**
- Данные представлены в табличном формате
- Логи и подзадачи в отдельных секциях (не вложены)
- Удобно открывать в Excel, Google Sheets, Numbers
- Каждая секция - отдельная таблица

---

### Markdown (.md)

**Структура:**
- Заголовки с эмодзи для навигации
- Таблицы для метрик благополучия
- Вложенные списки для логов и подзадач
- Теги для категоризации (в формате `#tag`)

**Особенности:**
- Красивое форматирование для чтения
- Поддерживает wikilinks для Obsidian
- Frontmatter для метаданных
- Легко копировать в Notion, Obsidian, другие Markdown редакторы
- Полная история чата с нумерацией сообщений

**Секции:**
1. `# Personality Architect - Экспорт данных` - заголовок
2. `## 👤 Профиль` - информация о пользователе
3. `## ✅ Привычки` - список привычек с логами внутри каждой
4. `## 🎯 Цели` - список целей с подзадачами внутри каждой
5. `## 🎡 Колесо жизни` - оценки, сгруппированные по неделям
6. `## 📊 Метрики благополучия` - таблица всех записей
7. `## 💬 История чата с AI коучем` - все сообщения по порядку

---

## 🔒 Безопасность и конфиденциальность

### Что НЕ экспортируется:
- ❌ Технические ID (id, user_id, habit_id, goal_id, и т.д.)
- ❌ Farcaster ID (fid)
- ❌ Внутренние коды и служебные поля
- ❌ Служебные timestamps (created_at, updated_at в техническом виде)

### Что экспортируется:
- ✅ Только понятные пользователю данные
- ✅ Названия, числа, даты в читаемом формате
- ✅ Все данные пользователя без ограничений
- ✅ Полная история активности

### Процесс экспорта:
1. Пользователь запрашивает экспорт через UI
2. Генерируется временный токен (действует 5 минут)
3. Токен содержит userId и формат экспорта
4. Скачивание происходит через защищенный endpoint
5. Токен используется один раз и помечается как использованный

---

## 🎨 Улучшения читаемости

### Форматирование дат:
- Все даты в формате `DD.MM.YYYY` (русская локаль)
- Время в формате `DD.MM.YYYY, HH:MM:SS` для истории чата

### Булевы значения:
- В JSON: `true` / `false`
- В CSV/Markdown: `Да` / `Нет`, `Активна` / `Неактивна`

### Структура данных:
- В JSON/Markdown: иерархическая структура (логи внутри привычек)
- В CSV: плоская структура с связями по названиям (логи ссылаются на привычку по названию)

## 🔌 API Endpoints

### POST `/api/export/download-link`

Генерирует временную ссылку для скачивания.

**Тело запроса:**
```json
{
  "format": "json" | "csv" | "markdown"
}
```

**Ответ:**
```json
{
  "url": "https://.../api/export/download?token=...",
  "expiresAt": "2024-01-25T12:05:00Z"
}
```

### GET `/api/export/download?token=...`

Скачивает файл с данными пользователя.

**Параметры:**
- `token` - временный токен (UUID или JWT)

**Ответ:**
- Файл в выбранном формате с заголовками для скачивания

### GET `/api/export/data?format=...`

Старый endpoint для прямого экспорта (для обратной совместимости).

**Параметры:**
- `format` - формат экспорта (json, csv, markdown)

## 📁 Файлы системы

- `src/app/api/export/download/route.ts` - основной endpoint для скачивания
- `src/app/api/export/download-link/route.ts` - генерация временных ссылок
- `src/app/api/export/data/route.ts` - старый endpoint (обратная совместимость)
- `src/app/profile/page.tsx` - UI для экспорта

## 🎯 Использование

1. Пользователь заходит в профиль
2. Видит секцию "Экспорт данных"
3. Выбирает формат (JSON, CSV, Markdown)
4. Нажимает "Копировать" или "Скачать"
5. Получает полный архив своих данных
