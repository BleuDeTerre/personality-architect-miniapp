# Profile System (Система профиля)

## 📋 Обзор

Система профиля позволяет пользователям управлять своими данными, просматривать статистику, настраивать главную цель жизни и управлять кошельком.

---

## 🔌 API Endpoints

### 1. Главная цель жизни

**GET** `/api/profile/main-focus`

**Ответ:**
```json
{
  "main_focus": "Build a successful startup"
}
```

**POST** `/api/profile/main-focus`

**Тело запроса:**
```json
{
  "main_focus": "Build a successful startup"
}
```

**Логика:**
- Сохранение главной цели жизни пользователя
- Используется в AI промптах для персонализации

**Файл:** `src/app/api/profile/main-focus/route.ts`

---

### 2. Кошелек

**GET** `/api/profile/wallet`

**Ответ:**
```json
{
  "wallet_address": "0x..."
}
```

**POST** `/api/profile/wallet`

**Тело запроса:**
```json
{
  "wallet_address": "0x..."
}
```

**Логика:**
- Сохранение адреса кошелька пользователя
- Используется для NFT минтов и платежей

**Файл:** `src/app/api/profile/wallet/route.ts`

---

### 3. Очистка данных

**POST** `/api/profile/clear-data`

**Тело запроса:**
```json
{
  "confirm": true
}
```

**Логика:**
- Удаление всех данных пользователя
- Каскадное удаление через CASCADE constraints
- Необратимая операция

**Файл:** `src/app/api/profile/clear-data/route.ts`

---

## 🗄️ База данных

### Таблица `users` (расширение)

```sql
ALTER TABLE users ADD COLUMN main_focus TEXT;
ALTER TABLE users ADD COLUMN wallet_address TEXT;
```

**Поля:**
- `main_focus` - главная цель жизни (используется в AI)
- `wallet_address` - адрес кошелька (для NFT и платежей)

## 🔐 Безопасность

### Row Level Security (RLS)

**Политики:**
- Пользователь может видеть/обновлять только свой профиль
- Главная цель и кошелек - приватные данные

**Проверка:**
- Все API endpoints проверяют `user_id` через `requireUserFromReq()`
