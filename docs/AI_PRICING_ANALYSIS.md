## 💸 Стоимость OpenAI API

### Примерная стоимость одного запроса AI Chat:

**Входящий промпт (system + context):**
- ~2000-4000 токенов (зависит от объема данных)
- При использовании `gpt-4o-mini`: $0.150 / 1M input tokens
- Стоимость: **$0.0003 - $0.0006** за запрос

**Исходящий ответ:**
- ~100-500 токенов
- При использовании `gpt-4o-mini`: $0.600 / 1M output tokens  
- Стоимость: **$0.00006 - $0.0003** за ответ

**ИТОГО:** ~**$0.0004 - $0.0009** за один запрос к AI Chat

### При масштабе:
- 1000 запросов/день = $0.40 - $0.90/день = **$12 - $27/месяц**
- 10,000 запросов/день = $4 - $9/день = **$120 - $270/месяц**

## 🤔 Рекомендации

### ❌ **НЕ стоит полностью отключать AI для Free пользователей**

**Причины:**
1. **Маркетинговая ценность** - AI Chat - это "wow-фактор", который привлекает пользователей
2. **Конверсия** - Пользователи попробуют AI, увидят ценность и захотят больше (Pro)
3. **Конкуренция** - Многие приложения предлагают базовый AI бесплатно
4. **Пользовательский опыт** - Резкое ограничение может оттолкнуть пользователей

### ✅ **Рекомендуемая стратегия:**

#### **Вариант 1: Ограничения по частоте (Freemium)**

**Free пользователи:**
- ✅ 5-10 запросов к AI Chat в день
- ✅ Ограниченный контекст (например, только последние 7 дней данных)
- ✅ Базовые AI функции (daily-motivation, alerts)

**Pro пользователи ($4.99/мес):**
- ✅ Неограниченные запросы
- ✅ Полный контекст (3 месяца данных)
- ✅ Все AI функции

**Premium пользователи ($9.99/мес):**
- ✅ Всё из Pro
- ✅ Приоритет обработки
- ✅ Расширенные AI insights

**Преимущества:**
- ✅ Контролируем затраты
- ✅ Мотивируем апгрейд
- ✅ Сохраняем ценность для Free

#### **Вариант 2: Гибридная модель**

**Free пользователи:**
- ✅ AI Chat доступен, но:
  - Только базовые вопросы (статистика, прогресс)
  - Без глубокого анализа
  - Без корреляций и паттернов
  - Ограничение: 3-5 запросов в день

**Pro пользователи:**
- ✅ Полный AI Chat без ограничений
- ✅ Все аналитические вопросы
- ✅ Расширенный контекст

**Преимущества:**
- ✅ Базовая ценность для Free
- ✅ Ясное различие между планами
- ✅ Контроль затрат

#### **Вариант 3: Pay-per-use для Free**

**Free пользователи:**
- ✅ AI Chat доступен
- 💳 Каждый запрос стоит $0.002-0.005 (через X402)
- ✅ Пользователь платит только за использование

**Pro пользователи:**
- ✅ Включены 50-100 запросов/месяц
- ✅ Дополнительные запросы по pay-per-use

**Преимущества:**
- ✅ Полный контроль затрат
- ✅ Пользователь платит только за использование
- ✅ Справедливая модель

### 1. Добавить проверку плана в `/api/chat/message`:

```typescript
// Проверка плана пользователя
const { data: planData } = await supa
    .from('user_plans')
    .select('plan, plan_until')
    .eq('user_id', userId)
    .maybeSingle();

const userPlan = planData?.plan ?? 'free';
const isPro = ['pro', 'premium'].includes(userPlan);

// Для Free пользователей - проверка лимита
if (!isPro) {
    const today = new Date().toISOString().slice(0, 10);
    const { data: dailyRequests } = await supa
        .from('events_log')
        .select('id')
        .eq('user_id', userId)
        .eq('name', 'ai_chat_request')
        .gte('created_at', `${today}T00:00:00Z`)
        .lt('created_at', `${today}T23:59:59Z`);

    const FREE_DAILY_LIMIT = 5; // 5 запросов в день
    if ((dailyRequests?.length || 0) >= FREE_DAILY_LIMIT) {
        return NextResponse.json(
            { 
                error: 'daily_limit_reached',
                message: 'You have reached your daily limit. Upgrade to Pro for unlimited AI Chat!',
                limit: FREE_DAILY_LIMIT,
                upgradeUrl: '/pricing'
            },
            { status: 429 }
        );
    }

    // Логируем запрос
    await supa.from('events_log').insert({
        user_id: userId,
        name: 'ai_chat_request',
        props: { plan: 'free' }
    });
}
```
